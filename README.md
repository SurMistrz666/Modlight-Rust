# Modlight (Rust)

Przepisanie serwera Modlight i aplikacji Modlight App na Rust.

- `server/` - serwer (Rust + panel WWW), zasady w `server/docs/PORT.md`
- `app/` - aplikacja na macOS (Rust), zasady w `app/docs/PORT.md`
- `docs/audyt/` - audyt oryginalnego kodu (2026-10-18)

Oryginaly (tylko do odczytu, poza gitem): `upstream/Modlight`, `upstream/Modlight-App`.
Wszystko dziala tylko lokalnie na tym Macu (porty 127.0.0.1).
